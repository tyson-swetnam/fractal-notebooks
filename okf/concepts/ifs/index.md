# Iterated Function Systems

* [Barnsley Fern](barnsley-fern.md) - Iterated function system (IFS) of four affine maps that produces a fern-like attractor and is a classic biological-fractal example.
* [Iterated Function System](iterated-function-system.md) - Finite collection of contraction mappings on a complete metric space whose attractor is a (typically fractal) compact set, by the Hutchinson theorem.
